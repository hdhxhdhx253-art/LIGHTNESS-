## Railway
1. Keep the existing Railway service.
2. Replace the GitHub files with this package.
3. Keep/add Railway Variable: `DISCORD_TOKEN` = your Discord bot token.
4. Deploy/Redeploy. Start command is `python bot.py`.
5. Do not put the real token in GitHub.

## Included
General, moderation, permission-controlled commands, ticket creation/panel, reports, welcome/goodbye, giveaways, emergency lockdown, and defensive anti-nuke monitoring.

## Emoji
The supplied custom emoji IDs are centralized in `bot.py`. The bot resolves them from IDs automatically when those emojis are available in the server. Extra normal Unicode emojis are also used for buttons and fallbacks.

## Important permissions
Give the bot only the permissions it needs. For moderation/anti-nuke actions, its role must be high enough in the server hierarchy. No Discord bot can honestly guarantee 100% bypass-proof security, especially against the server owner or a compromised high-privilege account.
